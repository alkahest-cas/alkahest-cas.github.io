Plotting, printing and parsing

function 
latex(expr) → str
#source

Return a LaTeX string for the given Expr.

A Series (from series()) renders its expansion with the O(·) term, and a DerivedResult renders its .value.

The result is suitable for $...$ in a LaTeX document or IPython.display.Math(alkahest.latex(expr)) in a Jupyter notebook.

Example:

Python
>>> import alkahest
>>> p = alkahest.ExprPool()
>>> x = p.symbol("x")
>>> alkahest.latex(alkahest.sin(x)**2 + alkahest.cos(x)**2)
'\\sin\\!\\left(x\\right)^2 + \\cos\\!\\left(x\\right)^2'

function 
plot_dag(expr, *, title: str | None=None, **kw: Any)
#source

Visualise the expression DAG.

Tries the graphviz Python package first (renders a nice PNG/SVG via system Graphviz). Falls back to returning the raw DOT string so the caller can pipe it to dot manually.

Parameters
exprExpr — the expression to visualise.
Returns

graphviz.Source — if the graphviz package is installed.

str — raw DOT string otherwise.

Return a standalone SVG string for the expression (no Python dep needed).

This calls the Rust render_svg function directly and requires no matplotlib / plotly installation. The result can be:

  • Written to a .svg file.
  • Embedded in HTML as <img src="data:image/svg+xml;base64,...">.
  • Displayed in Jupyter: IPython.display.SVG(alkahest.plot_svg(...)).
function 
unicode_str(expr) → str
#source

Return a Unicode pretty-printed string for the given Expr.

Uses Unicode superscripts, Greek letters, fraction characters, and root symbols for a human-readable representation without LaTeX markup.

Example:

Python
>>> import alkahest
>>> p = alkahest.ExprPool()
>>> x = p.symbol("x")
>>> alkahest.unicode_str(x**2 + p.integer(1))
'x² + 1'
