Tensor calculus API

Metric → Christoffel → Riemann / Ricci / Einstein / Weyl on a coordinate chart, and an abstract-index layer with Einstein summation (tensor).

Every component is computed in an exact field: integer polynomials over the coordinates, the parameters and one generator per transcendental atom (sin/cos, sinh/cosh, exp, log, radicals, undefined functions such as a(t) and their Derivative nodes), with sin² = 1 − cos², cosh² − sinh² = 1, i² = −1 and (√b)² = b applied and every denominator made free of sin, radicals and i. That normal form is canonical, so a component that vanishes identically is the literal 0 and a non-zero one is never reported as zero — no sampling, no floats. Only independent components are computed; the rest follow by symmetry.

Conventions (MTW / Carroll / Wald): Γ^a_{bc} = ½ g^{ad}(∂_b g_{dc} + ∂_c g_{db} − ∂_d g_{bc}), R^a_{bcd} = ∂_c Γ^a_{db} − ∂_d Γ^a_{cb} + Γ^a_{ce}Γ^e_{db} − Γ^a_{de}Γ^e_{cb}, R_{bd} = R^a_{bad}, G_{ab} = R_{ab} − ½ R g_{ab}, K = R_{abcd}R^{abcd}; the 2-sphere of radius ρ has R = 2/ρ².

#Metric

class 
class Metric(g: Any, coords: Sequence[Expr])
#source

A (pseudo-)Riemannian metric g_{ab} on the chart coords.

Parameters
glist of lists or Matrix

The symmetric components g[a][b] (Expr, int or Fraction).

coordssequence of Expr

Distinct coordinate symbols, one per row.

Raises
TensorError

E-TENSOR-001 (shape / coordinates), E-TENSOR-002 (not symmetric), E-TENSOR-003 (determinant identically zero), E-TENSOR-004 (a float entry), E-TENSOR-005 (Piecewise or another node the exact field cannot hold).

Every curvature method is computed once and cached; timings() reports the wall time of each stage.

class 
class Tensor(
    components: Any,
    variance: str | Sequence[Any],
    metric: Metric | None=None
)
#source

Components of a tensor with a fixed variance per slot.

Parameters
componentsnested lists

components[i][j]... (rank-many levels; a bare Expr for rank 0).

variancestr

One character per slot: "u" (contravariant) or "d" (covariant), e.g. "uddd" for R^a_{bcd}.

metricMetric, optional

Used to raise/lower slots when indexed in the other variance, and to simplify components.

T[0, 1] (integers) is a component; T[-a, -b] (indices) is an IndexedTensor.

#source

Nested lists of components (zeros as 0).

class 
class IndexedTensor(
    data: dict[tuple[int, ...], Any],
    free: Sequence[TensorIndex],
    dim: int,
    metric: Metric | None
)
#source

A tensor with named free indices, the result of indexing a Tensor.

Supports +, -, * (outer product with Einstein summation over a repeated index, once up once down), scalar *//, symmetrize(), antisymmetrize(), and tensor() / components to read the result. Components are kept in the metric's canonical form, so a combination that vanishes is 0.

Properties
components: Any
#source

Nested lists of components, slots in free order.

Methods
symmetrize(*idx: Any) → IndexedTensor
#source

T_{(ab)} = ½(T_{ab} + T_{ba}) over the named free indices.

antisymmetrize(*idx: Any) → IndexedTensor
#source

T_{[ab]} = ½(T_{ab} − T_{ba}) over the named free indices.

tensor() → Tensor
#source

A Tensor with slots in free order.

component(*idx: int) → Any
#source

The component at integer indices (slots in free order).

is_zero() → bool
#source

True when every component is exactly zero (canonical form).

Refusals are TensorError (E-TENSOR-001 … E-TENSOR-010); see errors.
